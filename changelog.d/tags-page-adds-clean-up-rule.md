### Added
- **The Tags page can add a clean-up rule.** Renaming, merging or deleting a tag stays a one-off edit, but an admin can tick "Also add a rule in Metadata clean-up" to keep it: a rename stores "old becomes new", a delete stores a drop, and rules that produced the old name follow the change. The page says which rule was added and links to Metadata clean-up, where the rule can be changed or removed. Every Tags page edit is also listed in the clean-up page's History, where Undo puts the books back and then any rule it added, skipping anything changed since (Discussion #2481, #2438).
