### Added
- **Metadata clean-up rules can apply to new books.** Each field in Metadata clean-up has an "Apply these rules to new books" switch, off by default. With it on, a new book's own tags and publisher are mapped right after import, automatic metadata fetch maps what it brings in, and Fetch metadata shows its results already mapped, so "Fiction / Thrillers" arrives as "Thriller" and a dropped tag never arrives. Each import the rules changed is listed in the clean-up page's History, where Undo puts the book's own values back. With "Only approved values" also on, values nobody approved stay out of new books too. Any failure leaves the metadata as it came; it never stops an import or a fetch (#2438, Discussion #2481).
