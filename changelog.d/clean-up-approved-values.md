### Added
- **Approved values, and an opt-in "Only approved values" switch, in Metadata clean-up.** Each tag or publisher in the library shows whether it is approved, renamed, dropped or not decided yet, and can be approved one at a time or all shown at once ("Approve 12 shown"). With "Only approved values" on for a field, a value that is not approved and has no rule is dropped when the rules are applied; the preview shows exactly which books would lose what before anything is written. The switch is off by default, so nothing changes for a library that never sets it up. Approvals travel in the JSON export as rules that map a value to itself (#2438).
