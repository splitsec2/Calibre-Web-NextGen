### Added
- **Publishers in Metadata clean-up, and rename on the Publishers page.** Publishers get their own tab in Metadata clean-up: a rule renames a publisher or drops it (one name or none, since a book has one publisher), with the same preview, apply and undo as tags. The Publishers page can now rename a publisher, and merge it into an existing one on a name clash, for every book at once. There is no delete there, since that would leave books with no publisher. Admins get the same "Also add a rule in Metadata clean-up" box as on the Tags page, and every edit there is listed in the clean-up page's History with Undo.
